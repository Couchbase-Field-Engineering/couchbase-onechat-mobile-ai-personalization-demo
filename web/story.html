Chapter 2 · What goes wrong

Four things break a company-wide chatbot. Each one has a fix.

The model's price per token is the smallest part of it. What matters is how often you call it, how much you send it - and what it is allowed to see.

1

Repeat questions

Store hours, the return policy, how to reset a password: the same for everyone who asks. Generating each one again is pure waste.

calls × people
2

Context rebuilt every turn

A personal answer needs the person's record from the CDP, CRM or HRIS, the relevant policy and live data. Rebuilding and re-sending that for every question is the largest prompt in the app.

tokens per call
3

One bot, everyone's knowledge

Put the Help Center and the HR handbook in one vector store and a shopper's question can retrieve a benefits policy - or another person's profile.

the risk
4

No answer offline

On a train, a shop floor or a loading dock there is no signal. Every question that can't be answered becomes a call later, or a lost sale.

the hidden cost

LLM Cache

The second person to ask a shared question gets the first person's answer: an exact or semantic hit, zero tokens. Shared answers hold no personal data, so sharing them is safe.

Couchbase LLM Cache

Context Cache

The context assembled for a person and topic is cached with a key of user, intent, export date and profile revision. Follow-ups reuse it; a new export or anything the person does invalidates it.

Couchbase Context Cache

Two scoped RAG applications

A customer app scoped to the Help Center and a workplace app scoped to the Team Handbook. An audience gate routes by who is signed in; personal retrieval is filtered to the asker's own profile document.

Answers on the phone

Chapter 4 · The same questions, two bills

Five questions: three model calls instead of five, and an answer offline.

The same people ask the same things of two chatbots: one that runs through the Couchbase Labs Agent Operations Manager with its context on the phone, and one that calls the model every time.

1

Maya: "What is your return policy?"

A shared question. Couchbase Labs Agent Operations Manager: the customer RAG app retrieves the scoped Help Center, generates once, and caches the answer. Plain chatbot: generates.

2

Daniel asks the same thing

Couchbase Labs Agent Operations Manager: LLM Cache exact hit - no tokens, no latency. Shared answers carry no personal data, so sharing is safe. Plain chatbot: generates again.

3

Maya: "Where is my order?"

A personal question. Couchbase Labs Agent Operations Manager: builds her context once (her CDP record, her profile document, live order data), stores it in the Context Cache and in Couchbase, then generates. Plain chatbot: rebuilds the whole prompt and generates.

4

Maya: "Can I reschedule my delivery?"

Couchbase Labs Agent Operations Manager: Context Cache hit - a short call on the cached context, with memory of the earlier turn. Plain chatbot: the full prompt again, plus the history.

5

On the subway, no signal: "When does my desk arrive?"

Couchbase Labs Agent Operations Manager: her orders and the cached context already synced to her phone; Couchbase Lite answers. Plain chatbot: can't reach the server.

A six-minute script

  1. Pay once. Sign in as Maya and ask "What is your return policy?" The chips show LLM cache · miss: the customer RAG app generated it from the scoped Help Center.
  2. Share it. Sign in as Daniel and ask the same thing: LLM cache · exact hit. Reword it: a semantic hit. Open Couchbase Labs Agent Operations Manager's RAG Applications page - the hit is counted against onechat-assistant.
  3. Build context once. As Maya: "Where is my order?" shows Context cache · built and the CDP round trip. Ask when the package arrives: Context cache · hit. Open sources: her own profile and the Help Center, nothing else.
  4. Try the wrong door. Still as Maya: "How do I reset my VPN password?" The Audience gate refuses, and nothing was retrieved. Sign in as Sofia and ask it: answered from the Team Handbook by onechat-workplace. Profile → Offline & sync shows her employees channel.
  5. Go offline. As Maya, Profile → Offline mode. Ask about the order again: Answered on device · Couchbase Lite. Start the chair exchange from For You; it shows "On device".
  6. Back online. Turn Offline mode off: the exchange syncs and Confirm triggers the OneChat Returns Agent - a second Couchbase Labs Agent Operations Manager identity scoped to the order-and-return tools. It recalls her return history from Couchbase Labs Agent Operations Manager Agent Memory, processes the exchange as a governed tool call, and remembers the outcome. Then "My keyboard arrived with a broken key…" → request the store credit, and approve it in Couchbase Labs Agent Operations Manager → Approvals.
